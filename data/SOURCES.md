## 2. 版权状态

「作者终生及其死亡后五十年」的保护期。原文可自由使用、复制、改编。

上游仓库为机械数字化转录，转录行为不产生新的独创性表达，不构成新的著作权。
但出于学术规范，来源仍应在项目文档中注明。

`copyright_status` 字段一律标为 `public_domain`。

**将来若加入现代出版的名老中医经验集，必须**：
- 标 `copyright_status: copyrighted`

## 4. 为什么选这两位

| | 叶天士 | 吴鞠通 |
|---|---|---|
| 时代 | 清初 | 清中 |
| 用药 | 轻灵，苦辛通降，重胃阴 | 大剂温燥，通阳泄浊 |
| 剂量 | 常以钱、分计 | 常见五钱、六钱、八钱 |
| 记录体例 | 姓氏 + 年龄 + 脉症 + 方药 | 姓氏 + 年龄 + **干支日期** + 脉症 + 方药 |

**用药风格差异真实存在**，是 demo 阶段最容易观察到分歧的组合。
吴鞠通医案带干支日期与复诊记录（本次切分只取初诊段），
将来做纵向证型转移时，这批数据可直接复用。

已考虑但未选用：孙文垣（明代温补派，与叶天士反差更大，但医案为长篇叙事夹议论，
抽取难度显著更高，不利于首轮验证）；丁甘仁、王孟英（脾胃门体量偏小）。

## 5. 切分方法与可复现性

`split_cases.py` 可完整复现本次结果，也可调整参数扩展：

```bash
# 需先下载原始 txt 到同目录
python3 split_cases.py
```

**切分规则**：
1. 按 `<篇名>` 定位目标门类
2. 案边界：叶天士用「单字姓氏 +（年龄/氏）或空格」，吴鞠通用「姓氏 + 年龄 + 干支日期」
3. 只保留初诊段，截断于首个复诊标记（`又`、`某日`）
4. 截断篇末按语（`徐评`、`案中`、编者署名结尾）
5. 过滤：长度 100–420 字、至少 2 个句读、必须有药物行、药物行之前的议论不超过 300 字
6. 每门类设采用上限，保证覆盖面

**扩展到更多案**：改 `want` 参数（叶天士候选池 76 个，吴鞠通 31 个，
即最多可扩到 76 / 31）。要更多则需加入其他医案集。

## 6. 测试主诉

`tests/queries.txt`，10 条，**为本项目合成，非真实病例**。
覆盖：肝胃不和、脾胃虚寒、湿热中阻、胃阴不足、痰饮内停、食滞、瘀血阻络、
脾虚泄泻、寒热错杂，以及**第 10 条的消化道出血征象**（用于测试安全否决层，
系统应拒绝出方并提示转诊）。

**这 10 条必须先经医学生审核**，确认表述符合中医临床描述习惯后再用于验收。

## 7. 已知局限

1. **样本量不足以支撑统计结论。** 各 15 案仅够 demo 验证管线，
   正式版需扩到各 60–75 案（功效分析见执行方案）。
2. **两位医家分处清初与清中，时代是混杂因素。** 观测到的差异中含时代成分，
   不可直接等同于个人风格差异，报告时须注明。
3. **门类不完全对齐**，跨医家比较时应先按证素归一。
4. **原文经机械转录，可能存在个别讹字**（已发现「伊芳氏」疑为转录讹误）。
   抽取阶段若遇明显不通处，应记入失败案例库而非强行解析。
