## 一、为什么是统计而不是让模型总结

「叶天士在脾胃气虚证下常用党参、白术」这句话，让模型从医案里总结出来是**生成**，
会编；数出来是**计数**，不会。而且数出来的每一条都能回指到具体的 `case_id`，
模型总结的回指不了。这跟 X3 的 `RationaleRecord`（规则抽取而非 LLM 抽取）
是同一个选择，也是这一轮**零 LLM 调用**的原因：不是省钱，是这件事本身不该由模型做。

四类规律与各自的数据来源：

| kind | 挖的是什么 | 来源 | 条数 |
|---|---|---|---|
| `herb` | 高频药 | `herbs` 计数 | 309 |
| `herb_pair` | 常用药对 | `herbs` 两两共现 | 1241 |
| `dose` | 剂量习惯 | **从 `raw` 原文抓**（`herbs` 没有结构化剂量） | 194 |
| `modification` | 复诊加减 | 同一 `case_group_id` 前后两诊的药物差集 | 180 |

`herb_pair` **不做三味以上的组合**：组合数爆炸而 support 必然更低，
751 张方挖不出可信的三味组合。这是数据量的限制，不是没想到。

## 二、剂量抽取：让正则猜药名，抓到的是「少」「用」「得」

第一版的正则是「药名 + 数量 + 单位」：

```python
_DOSE_RE = re.compile(r"([一-龥]{1,6}?)\s*(\d+(?:\.\d+)?|[一二三四五六七八九十半]{1,3})\s*(钱|两|分|g|克)")
```

单元测试要是只写「柴胡三钱」这种理想写法，它会全绿。实测不是：

```
原文含任一单位字的方：751 / 751
正则能命中的方：      561 / 751
抓到 ≥1 个剂量的方：   69 / 751   ← 9%
正则实际抓到的「药名」：['一两六钱', '必用八分', '至一钱', '遂用一钱', '得一两', '少麻黄四钱']
```

根因是懒惰量词 `{1,6}?`：它取**最短**前缀，所以「少麻黄四钱」里药名位捕到的是
「少」，`normalize_herb("少")` 认不出来，这条剂量就被丢掉。
**正则不知道哪些字是药名，而这张方的药名本来就在 `herbs` 里。**

改成反向锚定：拿这张方真的开了的每一种写法去原文里找，再看紧跟其后的是不是剂量。

```
抓到 ≥1 个剂量的方：651 / 751   ← 87%
剂量值总数：9398 个
```

锚定之后要处理的是真实写法，全部取自原文并进了测试：

| 原文写法 | 出处 | 抽出 |
|---|---|---|
| `云苓(五钱)` | 吴鞠通 | 18.5g |
| `枳实(钱半)` | 吴鞠通 | 5.55g（倒装 = 一钱半） |
| `半夏(一两二钱)` | 吴鞠通 | 44.4g（**累加**，不是 37） |
| `川桂枝尖(生五钱)` | 叶天士 | 18.5g（炮制字夹在括号里） |
| `五灵脂(炒一两)` | 叶天士 | 37.0g |
| `小枳实(\n二钱)` | 吴鞠通 | 7.4g（括号里断行） |
| `生姜(三片)` / `白蜜(半酒杯)` | 吴鞠通 | **不抓**（片/杯不是重量单位） |
| `小温中丸三钱` / `服妙应丸六分` | 叶天士 | **不抓**（不是这张方任一味药的量） |

药名与剂量之间**刻意不允许任意汉字**（只许空白、括号、标点和最多两个炮制字）：
放开了「生石膏 防己(三钱)」会把防己的三钱记到生石膏头上。这条有测试钉住。

## 三、「永不裁」不等于「无上限」

R32 把规律段定成**永不裁**（`FOCUSED_CUT_ORDER` 里没有它）：砍掉它等于回到
「只有教材、没有这五位医家」。这一轮真数据到位后立刻暴露出这条的另一面：

`patterns_for(syndrome, physician)` 的证名匹配是 `key in group or group in key`，
而医家档的 `group_value` 是**空串**——空串是任何证名的子串，所以医家档
**恒命中任何证型**。1924 条里 1869 条是医家档。后果（同一份真数据、同一条主诉、
只改上限）：

| 上限 | 规律条数 | 规律段 token | 本草 | 方剂 | 裁掉了什么 |
|---|---|---|---|---|---|
| 不设 | 1869 | **230624** | **1 味** | 0 首 | formulary + materia_detail + materia_entries |
| 每位医家 12 条 | 36 | 11653 | 21 味 | 12 首 | 只标了 `patterns_per_physician_cap` |

230624 token 是 3 万预算的 **7.7 倍**，而规律段又不进裁剪循环——裁剪循环只好把
本草和方剂全砍掉，最后剩下 1 味药。**"永不裁"保的是这一段不被整段砍掉，
不是这一段没有上限**；两者混为一谈的结果是知识块里除了规律什么都没有。

修法三件：

1. `Ontology.sort_patterns()`（**单一实现**，`patterns_for` 与知识块合并后的重排
   都走它）：证型档优先 → support 从高到低 → `pattern_id` 兜底确定性。
   排过序，"取前 N 条"才是有意义的取法而不是碰运气。
2. 上限**按医家**而不是按总数：叶天士 390 张方、吴鞠通 284 张、张锡纯 77 张，
   按总数取前 N 会让案多的医家把案少的挤干净，"融合五家"就名存实亡。
3. 少放了什么必须可核：`stats` 里 `n_patterns`（放了）与 `n_patterns_available`
   （命中本次辨证的）并列，`trimmed_sections` 里记 `patterns_per_physician_cap`，
   段标题写「本次放入 36 条 …… 共 1869 条」——**任何数字都必须带对照**，
   模型也不该以为它看到的是全部。

顺带修掉的两处：一条规律的 `case_ids` 最多 223 个，全列出来一条就吃掉 2 千 token
（改成列前 8 条 + 写明总数）；医家档标题原来是光秃秃的 `### 叶天士·`，
读者看不出这条是"不分证型"还是"某个证型下"（改成 `叶天士·不分证型（该医家全部医案）`）。

## 四、两档分组：不是想多产一档，是只做证型档会挖空

`cases.json` 941 条在定位内的诊次里，只有 **116 条**标了证型（12.3%），
而这 116 条散在 **98 个不同证型**里。min_support=3 之下，
能进证型档的只有 **2 个证**：

| 证型 | 诊次 | 挖出规律 |
|---|---|---|
| 悬饮 | 6 | 51 条 |
| 胃阳虚 | 4 | 4 条 |
| 其余 96 个证 | 各 1~3 诊次 | 0 条 |

所以证型档只有 55 条，而且几乎全是「悬饮」。**只做证型档等于九成语料进不了规律层**，
只做医家档则丢掉了"他在这个证下怎么用药"这个更有用的粒度——两档都要，
`group_by` 字段必须在产物里，引用时能看出这条是哪一档。

这一条同时是 R38 的前置事实：证型档的 support 全部在 3~6 之间，
**任何基于证型档的结论都要标明它的 support**，不能只说"叶天士在悬饮下常用某药"。

李可与王云启那 134 条的 `herbs` 是空的——它们是**粗段直接入库、从未过 LLM 抽取**
的记录（`symptoms` / `syndrome` / `formula` 也全空），而李可的原文里明明有完整处方
（「生黄芪 120g, 当归、附子、川乌、防风、黑小豆各 30g……」）。

这一轮**不补**，理由两条：抽取要真实 LLM 调用（本轮定义是零 LLM）；
而且这两本书在 `data/local_corpora/MANIFEST.json` 里人工声明了 `out_of_scope`

`--include-out-of-scope` 才带上。判断只有一个来源（MANIFEST 写进记录的标记），
两处过滤都只读标记、不各自判一次。

**这条必须进 R38 的已知限制**：规律层覆盖 5 位医家里的 3 位，
两两配对的分歧度里凡涉及李可/王云启的那几对，规律层贡献为 0。

## 七、已知局限（如实记，不修）

1. **丸散方的两级用量。** 「姜半夏(十两)」= 370g、「广皮(五两)」= 185g 是制丸的
   一料总量，不是一次用量。原文里真有这个数，删掉等于篡改语料；中位数不受它影响，
   而 `dose_max_g` 会露出来——**所以 min/max 必须跟中位数一起报**，
   只报中位数就把这个局限藏起来了。
2. **`raw` 是粗段，一段里常含同一病人多次复诊。** 剂量归属到"这张方开过的药"
   而不是"这一诊开的药"，所以 `dose` 规律的 `support`（张数）与剂量值个数
   不是一一对应（9398 个值分布在更少的方里）。产物里两个数都在。
3. **上限 12 条是取舍不是测量。** 12 × 约 70 token ≈ 每位 850 token，
   五家约 4 千（预算的 14%）。`FOCUSED_MAX_PATTERNS_PER_PHYSICIAN` 环境变量可调。
4. **规律层不判"这个药该不该用"。** 它只说"这位医家在这些医案里这么用过"。
   该不该用由 R34 的符号验证器按本草本体判——两层的分界跟 R34 报告第一节同一条线。
