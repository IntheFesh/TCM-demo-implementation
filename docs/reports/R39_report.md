## 一、四行对比：为什么是这四行

答辩上问得最多的一句是「跟直接问大模型有什么区别」。§10.1 把它摆成四条路线
（通用大模型 / 检索增强 / 开源中医模型 / 本项目），**每一行都写两格**：
它给什么、它给不了什么。

关键的自律在最后一句：**每一行的"给不了什么"都必须对应本项目里一个具体机制，
而那个机制有它自己的数**。没有数的机制不写进那张表——否则这张表就变成了
一段宣传语，而宣传语在答辩现场是负资产（被追问一句就塌）。

配套的两节同样重要：
- §10.2 **现在量到了什么**：六行，其中两行是 ⏳（带上机命令）。⏳ 不是"没做"，
  是"这台机器上量不到"；跑完那条命令这一格就会有数，而不是跑完之后有人去改描述。
- §10.3 **明确做不到的三件事**：不是诊断工具 / 本体有长尾缺口（种数 39.8% vs
  次数 70.4%，两个数一起报）/ 五位医家里用药规律只覆盖三位。

## 二、申报书：把"我没动它"变成一条命令

用户手里那份申报书的**黑色正文一个字都不许变**。问题在于——
`python-docx` 打开再保存就会重写整个包（XML 重排、rsid 变化、部件顺序变化），
**文件层面的 diff 必然不一样**，肉眼和 `git diff` 都回答不了"正文有没有被改"。

所以校验的口径定在**文本层，而且按顺序比**：

```
指纹 = 把补充色（E54C5E）的 run 滤掉之后，剩下那串文字的 sha 序列
校验 = 新文件同样滤一遍，两条序列必须一字不差、一序不乱
```

**为什么不按 `(段落号, run 号)` 比**：往中间插一段，后面所有段落的下标整体后移，
按下标比会把每一段原文都报成"变了"。第一版就是这么写的，测试当场抓到
（`test_the_addition_lands_right_after_its_anchor` 让它红了）——而更值得记的是
那之后的推理：**一条会误报的校验，第二次就会被人加白名单绕过去**，那就白立了。

三条实现纪律，各有测试：
1. **不碰既有 run 的任何属性**——新增内容一律 `add_run()` / `insert_paragraph_before()`；
2. **不重排版**——不动页边距/页眉页脚、不插分页符（"黑字没变"在读者眼里
   包括"它还在原来那一页"）；
3. **加不进去就报错，不猜**——锚点找不到或撞名直接失败并列出最像的三段。
   猜一个位置插进去 = 把补充内容放在错的章节下面，**比没加更糟**。

还有一条容易被写反的：**上一轮补的红字不算原文，允许再改**。否则第二轮补充会
把第一轮的红字锁死，而那不是"黑字不许动"这条规则要保护的东西。

### 这一节最该被读到的一条

`test_verify_turns_red_when_a_black_run_is_edited` —— 故意改掉一处黑字，
校验必须报出是哪一条对不上。**一条只会绿的校验等于没有校验**：R37 那四张
空白截图就是这么全绿过去的（SOURCES 第 94 条）。

### ⏳ 申报书原件不在这个仓库里

所以这套工具**还没在真文件上跑过**，测试用的是合成 docx。上机第一步是
`fingerprint`（零风险、只读），那一步的输出就是"改之前长什么样"的凭据。
这一条如实写在 README、MATERIALS 和这里三处——**没跑过就是没跑过**。

| 教训 | 从哪几条长出来 |
|---|---|
| (a) 每个数必须带它的对照 | 45/74/78/89（手抄的数漂了四次）、86（一个比率两个分母）、100（消融的空格子有三种） |
| (b) 判据全绿 ≠ 东西是对的 | 70（两个回归在同一张截图上）、94（单链四张截图空白）、97（手写 fixture 跟真序列化漂了） |
| (c) 同一个概念只能有一处实现 | 「匹配逻辑只能有一处」那三次、31（physician 参数）、98（展示层第二次漏 id） |

做不到的那句话应该删掉——它多半是从别处读来的，不是这个项目挣来的。

## 四、一处口径说明（这一轮唯一拿不准的地方）

总纲给 R39 的原文里有一句「`data/SOURCES.md` 第 65~72 条要含四条教训」。
实际翻到那八条，它们是 R22~R26 那几轮的**逐轮记录**（方剂建议层、best-of-N、
八项前端改造、演示保险、蒸馏、R24 补丁、图的边属性、默认值改变），
**不是四条教训的容器**。

处理办法：**不去改那八条**（它们记的是当时的事故，改了就丢了原始记录），
而是新增第 101 条做索引，把四条教训分别指回它们真正长出来的那些条目——
其中确实包含 65~72 里的第 69、70、72 三条。如果总纲那句话指的是另一件事，
这一条随时可以按原意重写；但**把八条现成的事故记录改写成四条教训**这件事，
无论如何都不该做。
