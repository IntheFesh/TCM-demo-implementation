## 三条铁律的守卫

只填空槽（`herb.has(p)` 为真即跳过）；每行带 `dataset` 字段记来源数据集，
span 为空不收（`--stats` 仍是 0 条）；药典两张表逐一比对未变（62 味上限、24 对反畏）。
落盘前逐行过 schema——第一版把仓库路径写进 `source`（那是 `Literal["classic",
"modern"]`），380 行坏数据写进文件后才被既有测试抓出来，已改成写前挡住。

**别名两道守卫是被既有测试逼出来的**：「洋参→西洋参」当场弄红
`test_distinct_herbs_never_collapse_into_one_name`，加了「掉字写法一律丢」；
生成时若不清空上一轮的表，第二次跑会把 709 条覆盖成 1 行（实测 745→6）。

**可比性**：R38 的消融数字是在 235 首方剂上量的，知识块变了，重跑前不要并排放。
