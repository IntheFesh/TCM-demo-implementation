# 术语表

**这份表管的是「使用者能看到的文字」**——界面文案、导出文书、错误提示。
源码注释与内部文档不受它约束（注释里写「医生模式」不会让任何患者看到）。

分两类，判据不同：

- **第一类：同义异写。** 说的是同一件事，只是写法不同。**只许用一种**，
  `tests/test_glossary_consistency.py` 扫源码钉住。
- **第二类：近义但不同义。** 两个词各有各的意思，**都要用，但不许互换**。
  这一类没法靠扫词表自动判，表里写清楚区别，评审时按这张表看。

---

## 第一类：同义异写，只许用一种

| 只用这个 | 不用 | 为什么 |
|---|---|---|
| 医师 | 医生、大夫 | 《执业医师法》与医院文书用「医师」；「医生」是口语，「大夫」是方言 |
| 患者 | 病人 | 医院文书统一用「患者」 |
| 主诉 | 主述、诉求 | 「主诉」是病历书写规范里的固定字段名 |
| 舌象 | 舌相、舌苔象 | 「舌象」含舌质与舌苔两部分，是教材用词 |
| 脉象 | 脉相 | 同上 |
| 证型 | 症型、证形 | 「症」指症状，「证」指证候，混写会把两个层次搅在一起 |
| 本次记录编号 | trace_id、追踪号、会话 ID | 使用者要在电话里念给运维，得是一个中文说得出口的东西 |

## 第二类：近义但不同义，都要用，不许互换

| 词 | 指什么 | 跟谁容易混 | 区别 |
|---|---|---|---|
| **证候** | 一类病理状态的总称，是**分类层**（如「脾胃病证候」） | 证型 | 证候是门类，证型是门类下具体的那一个 |
| **证型** | 具体的那一个证（如「肝胃不和证」），是**结论层** | 证候 | 一次辨证的结论是证型，不是证候 |
| **治则** | 治疗的总原则（如「扶正祛邪」「调和阴阳」） | 治法 | 治则管方向 |
| **治法** | 落到具体的治疗方法（如「疏肝和胃」「健脾益气」） | 治则 | 治法管手段；本系统推导链里治则在治法之前一层 |
| **方剂** | 有名字的经典配伍（如「柴胡疏肝散」） | 处方 | 方剂是**书上的**，是知识 |
| **处方** | 医师这一次为这位患者写下的那一张 | 方剂 | 处方是**医师签的**，是医疗行为。系统给方剂，医师开处方 |
| **药味** | 方中的一味药 | 中药材 | 「药味」指方剂组成里的一个位置（君臣佐使）；「中药材」指药房里的那个东西 |
| **性味归经** | 本草层对一味药的属性记载 | 功效 | 性味归经是属性，功效是作用；本体里是两类不同的谓词 |

## 措辞红线（§0.4 合规定位）

系统输出的是**知识整理与依据呈现**，不是"建议对该患者采用 X 治疗"。
所以界面与文书里：

| 不许写 | 改写成 |
|---|---|
| 建议患者服用 XX 汤 | 本证型的教材代表方为 XX 汤 |
| 推荐采用该方治疗 | 该方的经典配伍为…（出处：…） |
| 应当使用 / 需服用 | 教材记载的用法为… |
| 方剂建议 | 方剂核查（这一层给的是对方子本身的核查结论） |

**就医指引不在红线内**：「建议尽快就诊」「建议就诊消化内科」是分诊导引，
不是诊疗建议，而且是安全边界的一部分（§8.3 第 21 条明确要求保留且更醒目）。
两者的区别是——前者说的是**去哪里**，后者说的是**吃什么**。
