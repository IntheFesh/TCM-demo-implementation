三步开始

  1. 输入什么：把患者的主诉与四诊文字描述写进下方输入框，包括舌象脉象的文字记录。越接近病历原文越好。
  2. 看什么：结果是一条自上而下的推导链——症状 → 脏腑病位 → 病性 → 证型 → 病机 → 治则 → 治法 → 方剂 → 君臣佐使。点任一节点看它的依据与原文出处。
  3. 怎么用：把推导链与出处作为辨证思路的参考；处方须由执业医师审核修改后签发。危重表现会在辨证开始前直接中止并给出就医指引。
